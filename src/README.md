# WorkBuddy 账号看板

一个本地运行的网站看板：多账号一键**每日签到 + 派小猫出行 + 给 AI 打招呼**，并显示每个账号的**积分余额与到期情况**。

单文件前端 + 一个本地后端，**只监听 127.0.0.1，凭据与 token 不出本机**。

---

## 快速开始（3 步）

### 1. 安装依赖

```bash
pip install requests
```

### 2. 登录（拿到自己的凭据）

```bash
python workbuddy_login.py
```

按提示输入手机号 → 收短信 → 输入验证码。成功后凭据会自动写入 **当前目录的 `wb_login_result.json`**。

> 想加多个账号：再跑一次，换另一个手机号即可，脚本会追加。

### 3. 启动看板

```bash
python server.py
```

浏览器打开 **http://127.0.0.1:8799** （换端口：`python server.py 9000`）

## 界面说明

**主页是账号卡片墙**，每个账号一张长方形卡片：

- 昵称 / 等级
- 今日签到 ✓ 或 ○、连签天数、能量值
- 🐱 小猫状态：旅行中（带倒计时）/ 已回来待领礼物 / 在家待命
- 右侧：积分剩余大数字 + 已用进度条 + 最近到期提醒

**点卡片展开详情**：

- 左：该账号每个积分包（剩余/总量、到期日、剩几天、来源徽章）
- 右：账号明细 + 该账号单独操作按钮（签到 / 派小猫 / 打招呼）

**顶部一键执行**：三个任务可勾选，对全部账号批量执行。

| 任务 | 说明 |
|---|---|
| 每日签到 | 接口幂等，已签到只返回提示，不会报错 |
| 派小猫出行 | 自动状态机：已到达 → 先领礼物；旅行中 → 报倒计时；空闲 → 出发 |
| 给 AI 打招呼 | 建会话后发一条消息，触发互动类成长任务 |

未登录时页面显示**演示数据**并禁用按钮，方便先看效果。

## 积分到期：全部来自官方接口，不做任何推算

数据来源：`POST /v2/billing/meter/get-user-resource` → `data.Response.Data.Accounts[]`

每个积分包都带官方真实到期字段：

- `CycleEndTime` —— 周期结束时间（循环包，如体验版月度额度）
- `DeductionEndTime` —— 扣减截止时间（一次性赠送 / 活动包）

判定口径（取自开源项目 CreditDaddy `src/workbuddyClient.js`）：

- `DeductionEndTime` 比 `CycleEndTime` 晚 **2 天以上** → 判为**循环包**，取 `Cycle*` 字段，到期看 `CycleEndTime`
- 否则为**一次性包**，取 `Capacity*` 字段，到期看 `DeductionEndTime`
- 已过期或总量为 0 的包自动过滤

> 注：老接口 `/billing/meter/get-user-resource-summary` **不返回到期日**，仅在 v2 接口不可用且无到期可显示时作为兜底（此时徽章会显示「估算」）。

### 为什么按到期日聚合显示

你的账号可能有**上百个积分包**（实测 117 个）。逐条列出会刷屏，所以看板按**到期日分组**：

- 每组显示：到期日期、还剩几天（≤3 天红 / ≤7 天橙）、该日到期积分合计、包含几个包
- 只展开最近 10 个到期日，更晚的汇总成一行
- 每张卡片右下角小字显示「最近到期 X 天后 · N 分」

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面（单文件，无需构建） |
| `server.py` | 本地后端，负责调用官方接口 |
| `fetch_state.py` | 数据读取封装（也可单独运行，输出 `dashboard_data.json`） |
| `workbuddy_login.py` | 短信登录工具，用于获取凭据 |

凭据读取优先级：环境变量 `WORKBUDDY_REFRESH_TOKEN`（多账号用换行或 `@` 分隔）> `wb_login_result.json` > `wb_refresh_tokens.json`。

## ⚠️ 重要提醒

1. **不要把 `wb_login_result.json` / `wb_refresh_tokens.json` 分享给任何人**——里面是你账号的 refresh token，拿到即可操作你的账号。本压缩包**不含**任何凭据文件（已确认）。
2. 这是**非官方工具**，接口通过逆向获得，与 WorkBuddy / 腾讯无隶属关系，可能随时失效。
3. 成长中心的写操作（派旅行、领礼物、发消息）+ 多账号属于**风控敏感区**。请仅用于本人合法持有的账号，不要批量注册小号、共享令牌或绕过风控。
4. 使用风险自负。

## 常见问题

**Q：页面一直显示演示数据？**
A：后端没读到凭据。确认登录脚本运行后，当前目录生成了 `wb_login_result.json`，或设置了环境变量 `WORKBUDDY_REFRESH_TOKEN`。修改后需**重启** `server.py`。

**Q：端口被占用？**
A：`python server.py 9000` 换一个端口。

**Q：某个账号显示"凭据失效"？**
A：token 过期或被服务端轮换。重新跑 `python workbuddy_login.py` 登录该账号，再重启后端。
